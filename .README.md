--> Django Weather Forecast API :

--> Overview:

--> Weather Forecast REST API (Django + DRF)

--> This project is a simple Django REST API that provides weather forecast data for 5 specific cities using the OpenWeatherMap API.

Allowed cities:

. Lahore
. Karachi
. London
. Tokyo
. New York

--> The user sends a city name, and the API returns:

. Current weather
. Wind speed
. Weather forecast (future hours)

--> Technologies Used

. Python
. Django
. Django REST Framework
. Requests library
. OpenWeatherMap API
